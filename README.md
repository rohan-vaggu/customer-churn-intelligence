# Customer Intelligence & Churn Prediction Platform

An end-to-end data analytics and machine learning project that identifies customers at risk of churn and provides actionable business insights.

## Project Status

🚧 In Development

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- PostgreSQL
- SQL
- Power BI
- Git & GitHub

## Objective

Build an end-to-end customer churn analytics platform that can:

- Analyze customer behavior
- Identify churn patterns
- Predict customers at risk of churn
- Quantify revenue at risk
- Provide actionable business insights
- Present insights through an interactive dashboard
